# PayLedger

PayLedger is a Java and Spring Boot learning project exploring backend engineering through a simulated digital wallet and payment system.

The project begins with Core Java and progressively evolves to cover Spring Boot, relational databases, concurrency, security, testing, distributed systems, and production engineering.

## Current Phase

**V0 — Java Foundations**

The current focus is learning Java fundamentals and implementing the core PayLedger domain without frameworks, databases, or external infrastructure.

## Goal

Build the project incrementally while developing a strong understanding of the language, tools, architecture, and engineering decisions behind each implementation.
